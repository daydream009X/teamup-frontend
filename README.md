# TeamUp · 竞赛组队平台 - 前端

## 1. 项目背景

TeamUp 是面向数学建模、程序设计、大创等竞赛的移动端组队平台，帮助参赛者和相关学生按竞赛方向和技能标签发现队友。用户可以搜索所需技能、查看候选队友，并创建或加入队伍，逐步补齐团队分工。本仓库为 Vue 3 前端，配套后端使用 Spring Boot（不在本仓库内）。

## 2. 技术架构

| 类别      | 技术                                              |
| --------- | ------------------------------------------------- |
| 框架      | Vue 3（Composition API + `<script setup>`）       |
| 语言      | TypeScript                                        |
| 构建      | Vite                                              |
| UI 组件库 | Vant 4（通过 `unplugin-vue-components` 按需引入） |
| 路由      | Vue Router 5（History 模式 + 路由守卫）           |
| 状态管理  | Pinia（集中登录态 + 共享当前用户请求）            |
| HTTP 请求 | Axios（请求/响应拦截器 + 开发/生产 API 地址切换） |
| 本地存储  | localStorage（搜索历史、主题偏好）                |
| 代码规范  | ESLint + Oxlint + Prettier                        |

## 4. 功能概览

### 用户与个人资料

- 用户注册、登录、退出；注册填写账号、密码和确认密码，按账号查重，昵称由前端生成默认值。
- 查看与编辑昵称、头像、性别、电话、邮箱和个人标签；提供七张可选头像及选择预览。
- Pinia 集中管理当前用户、初始化状态、加载状态和登录状态。
- 多个页面共享当前用户请求；登录或退出后，旧请求不会覆盖新的用户状态。
- 资料保存后刷新前端 Store，分别提示登录失效与用户信息刷新失败。

### 队友发现与标签搜索

- 首页提供推荐与标签相似匹配两种入口；匹配入口最多请求十位用户，推荐入口请求第一页、每页八位用户。
- 相似匹配由配套后端按标签序列的编辑距离排序，前端负责请求和展示。推荐接口优先读缓存，无缓存且用户标签字符串非空时也调用相似匹配，否则分页查询用户。
- 按完整标签名搜索，支持多标签组合；配套后端要求所有选中标签同时满足（AND），英文标签区分大小写。
- 输入关键词可筛选可选标签，按 Enter 直接搜索；支持跨分类多选后搜索。
- 热门标签提供上述八个静态竞赛与技能标签，点击即可搜索。
- 搜索成功后记录本地历史，空结果也属于成功；去重置顶、最多十条，支持单条删除、一键清空和跨标签页同步。
- 多标签搜索按各标签分别记录历史，点击历史项搜索该单个标签；请求失败不记录历史。

热门标签是静态推荐，不代表实时搜索量。实际搜索结果取决于后端用户数据；前端补充可选标签不会自动向数据库写入标签或演示用户。

### 队伍模块

- 创建、编辑公开 / 私有 / 加密队伍，填写人数、描述、到期时间和加密密码。
- 队伍列表支持游客访问、公开 / 加密分类切换与关键词搜索。
- 加入、退出、解散队伍，查看我创建的队伍和我加入的队伍。
- 创建队伍校验到期时间必填且晚于当前时间；编辑队伍校验非空到期时间。
- 加载、失败、空结果分别展示；查询失败可重试，旧请求不会覆盖新的列表。
- 操作中阻止重复点击；加密队伍密码错误时保留弹窗和输入，便于修改后重试。

### 通用交互

- 分类标签多选组件支持关键词筛选和锁定标签；个人标签编辑保留性别标签。
- “白日”与“白日做梦”两种主题，使用本地存储保存偏好。
- 路由守卫区分必须登录、可选登录和公开页面；登录后按站内路径回跳。
- Axios 携带 Cookie，处理未登录业务码；网络失败与权限不足不会被当作同一种登录失效。
- 页面部署在 `/teamup/` 子路径，Vue Router 自动使用 Vite 的基础路径。

## 5. 快速开始

### 环境要求

- Node.js：`^20.19.0 || >=22.12.0`
- pnpm / npm / yarn
- 联调时需另行启动配套 Spring Boot 服务，以及它依赖的 MySQL、Redis。前端开发服务器不会自动启动后端。

### 安装与运行

在前端仓库根目录执行：

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建生产版本
pnpm build

# 预览构建结果
pnpm preview
```

### API 配置与部署

开发环境 API 基地址为 `http://localhost:8081/api`；生产环境使用同域相对路径，由 Nginx 转发至后端。配置位于 `src/plugins/myAxios.ts` 中。页面基础路径配置在 `vite.config.ts`。
